# Redesign run

## Scope

- Onboarding
- Quotes home
- Meditation home
- History
- Shared visual direction for warm premium surfaces

## Strong existing decisions

- The project already has a clear contemplative palette instead of a generic blue AI palette.
- `Playfair Display` gives the app a distinct editorial tone.
- The main flows are already separated into focused UIKit modules, so UI upgrades can stay localized.

## Weak patterns found

- Several screens relied on flat headings over empty background space, which made the hierarchy feel unfinished.
- CTA styling was inconsistent across onboarding, quotes, and meditation.
- Some list cards still looked like default white boxes with light shadows.
- History lacked an orientation layer above the list, so the screen started abruptly.

## Changes made

- Added `codex-redesign-loop/` as a reusable audit and implementation loop.
- Reworked onboarding with a layered copy container, ambient gradient, and stronger primary CTA.
- Added a hero summary card to the quotes screen and tightened the type hierarchy.
- Added a summary card to history and upgraded conversation rows with better hierarchy and character badges.
- Added an intro card plus stronger CTA treatment to meditation.
- Refined meditation cards to feel lighter and more deliberate.

## Next batch

- Bring the same redesign pass to chat, scriptures, and settings.
- Normalize button radii, border opacity, and shadow tint through shared helpers or tokens.
- Review tab bar active-state behavior on device and tune optical spacing if needed.
