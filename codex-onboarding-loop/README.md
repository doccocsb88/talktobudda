# Codex Onboarding Loop

This folder is a dedicated loop for regenerating onboarding direction for `TalkToBudda`.

Use this loop when:
- the app positioning changes
- the onboarding copy no longer matches the product
- the app shifts away from a quotes-first flow
- the character system becomes a primary differentiator

Structure:
- `AGENTS.md`: rules for the onboarding image loop
- `input/`: positioning briefs, copy direction, screen goals
- `reviews/`: output notes, prompt logs, and selection decisions
