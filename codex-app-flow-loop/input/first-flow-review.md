# Character Selection To First Message Flow

## Goal

Review the first-time user flow from opening `Character Selection` to sending the first chat message.

## Screens In Scope

- Character Selection
- Chat screen after character choice

## What To Review

- Is it obvious who to choose first?
- Does the `Recommended` treatment help or distract?
- Does the screen feel too dense or still too generic?
- After selecting a character, does the transition into chat feel coherent?
- Does the first greeting support the selected character clearly enough?
- Is the path to sending a first message smooth for a new user?

## Risks To Check

- Character voices feel too similar after entering chat
- Recommended character overpowers the rest of the list
- The first chat state feels empty, confusing, or not personalized enough
- Switching from selection to chat feels abrupt

## Notes

- This review should consider both product clarity and likely implementation risks.
- Prefer practical feedback that can turn into design or iOS tasks quickly.
