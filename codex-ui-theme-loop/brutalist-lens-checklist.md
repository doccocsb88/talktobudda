# Brutalist Lens Checklist

This is an optional critique lens for `TalkToBudda`.

Use it to detect when the UI becomes too generic, too soft, or too template-like.
Do not use it as a command to make the whole app brutalist.

Principles:
- Strong hierarchy beats decorative softness
- Deliberate contrast beats polite sameness
- Memorable surfaces beat interchangeable app-store UI
- Personality must still respect readability and the product tone

Questions:
- Which screens feel visually timid?
- Where is the hierarchy too dependent on spacing instead of type contrast?
- Which surfaces would benefit from a sharper edge, stronger outline, or clearer contrast?
- Which cards feel like default templates rather than intentional product UI?
- Would a bolder move strengthen the brand, or just create inconsistency?

Safe brutalist-inspired moves:
- Stronger title contrast
- More decisive button hierarchy
- Sharper component outlines in selected areas
- Fewer decorative gradients and more content-led structure
- More confident section framing

Unsafe moves for this app:
- Turning every screen into harsh black-and-white contrast
- Using aggressive typography that hurts meditation or scripture readability
- Mixing brutalist accents into only one screen without system support
- Replacing calm spiritual tone with visual noise
