# App Store Screenshots Loop Review

## Current Product Angle

The product is no longer a Buddha-only experience. The App Store set should position it as a calm spiritual companion with multiple guides, reflective conversation, daily ritual, and emotionally safe support.

The key conversion challenge is balance:
- broad enough to support multiple guides
- specific enough to feel desirable
- calm enough to feel trustworthy
- differentiated enough to stop the scroll

## Six-Screen Narrative

1. Positioning hook
2. Choose the right guide
3. Talk through what you feel
4. Find calm and clarity
5. Return anytime
6. Brand promise close

## Prompts Used

Primary generation prompt:

```text
Create a premium App Store Connect iPhone screenshot campaign board for a spiritual guidance mobile app.

Use case: ui-mockup
Asset type: App Store Connect screenshot campaign
Primary request: generate 6 vertically composed iPhone App Store screenshots that act like advertisements, not documentation

Product:
- multi-guide spiritual companion
- reflective conversation
- calm ritual
- emotionally safe support
- not Buddha-only

Visual direction:
- warm ivory background
- deep forest green typography
- soft gold accents
- premium editorial calm
- spacious layouts
- believable iPhone product framing

Narrative sequence with one screen each:
1. Positioning hook: spiritual guidance for modern life
2. Choose the right guide: different voices for different moments
3. Talk through what you feel: ask real questions, receive thoughtful reflection
4. Find calm and clarity: ritual, meditation, grounding, presence
5. Return anytime: support throughout the day
6. Brand promise close: calm, wisdom, presence

Copy rules:
- short headline per screen
- optional brief support line
- no long paragraphs
- no feature checklist
- no crowded UI
- keep brand/app name minimal or absent so the set survives a rename

Constraints:
- screenshots are advertisements, not tutorials
- do not frame the app as Buddha-only
- do not make the set look like a game roster
- keep all 6 screens visually related but not repetitive
- each screen should sell one distinct outcome
- front-facing iPhone screens arranged in one premium comparison board
- add small numeric labels 1 to 6 below or above each screenshot for review clarity

Avoid:
- loud gradients
- childish illustrations
- generic SaaS banners
- over-detailed fake UI
- repetitive copy rhythm
```

## Set-Level Review

This first pass is promising. It already looks like a premium App Store campaign instead of a raw UI gallery, and the visual language is consistent across all 6 screens.

What is working:
- strong visual cohesion
- premium warm/green/gold palette
- good narrative arc from hook to close
- screen 1, 3, 4, and 6 are commercially strongest

What is weak:
- screen 2 currently drifts toward a character roster
- screen 5 looks more like notification lifestyle support than a spiritually grounded daily ritual
- some copy is solid but still a little generic in places

Set verdict:
- strong enough to continue from
- not ready for final export without targeted regeneration on the weaker screens

## Recommended Next Pass

Keep unchanged:
- screen 1
- screen 4
- screen 6

Refine:
- screen 3
  - simplify the conversation UI
  - keep the emotional value but reduce text density

Regenerate:
- screen 2
  - show guide choice as emotional fit, not a character grid
  - less roster, more “the right voice for this moment”
- screen 5
  - reframe as a gentle daily companion
  - less notification-center aesthetic, more ritual continuity

## Recommendation

This first run is a good foundation, not a final set.

Best next move:
1. lock screens 1, 4, and 6
2. refine screen 3
3. fully regenerate screens 2 and 5
4. then review the six-screen set again as a campaign, not as isolated screens
