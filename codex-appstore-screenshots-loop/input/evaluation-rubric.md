# Evaluation Rubric

Score each screenshot from `1` to `10` on these dimensions.

## 1. Scroll-Stopping Power

Questions:
- Would this screen make someone pause on the App Store page?
- Is the first idea immediately visible?

## 2. Positioning Clarity

Questions:
- Does the screen reinforce the right product category?
- Does it support a multi-guide spiritual companion story?

## 3. Copy Quality

Questions:
- Is the headline short, strong, and non-generic?
- Does the support line help instead of repeating?

## 4. Visual Cohesion

Questions:
- Does this screen belong to the same set as the other 5?
- Is the layout premium and intentional?

## 5. Screenshot-as-Ad Quality

Questions:
- Is this selling an outcome rather than documenting features?
- Does it make the product feel desirable?

## 6. Export Readiness

Questions:
- Could this screen move to final production with minor cleanup?
- Is the composition plausible for App Store usage?

## Set-Level Review

Also evaluate the 6-screen set as a whole:
- does the narrative progress well?
- is there enough variation across screens?
- are any two screens redundant?
- is the last screen a strong close?

## Recommendation Format

For each screen include:
- total score out of `60`
- strongest quality
- main weakness
- whether to keep, refine, or regenerate
