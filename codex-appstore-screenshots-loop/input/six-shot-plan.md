# Six-Screen Narrative Plan

Each screenshot should sell one idea.

## Screen 1: Positioning Hook

Purpose:
- stop the scroll
- communicate the app category fast

Message territory:
- spiritual guidance for modern life
- calm support when you need it

## Screen 2: Choose the Right Guide

Purpose:
- explain the multi-guide differentiator

Message territory:
- different voices for different moments
- choose the guide that fits your need

## Screen 3: Talk Through What You Feel

Purpose:
- show conversation value

Message territory:
- ask real questions
- receive thoughtful reflection

## Screen 4: Find Calm and Clarity

Purpose:
- connect to meditation / ritual / daily grounding

Message territory:
- daily moments of stillness
- grounding practices and presence

## Screen 5: Return Anytime

Purpose:
- sell retention and trust

Message territory:
- a guide in your pocket
- support throughout the day

## Screen 6: Close With Brand Promise

Purpose:
- leave one memorable emotional promise

Message territory:
- calm, wisdom, presence
- guidance that meets you where you are

## Copy Rules

- one headline per screen
- optional short supporting line
- no paragraph copy
- no feature checklist language
- no overloaded screenshots
