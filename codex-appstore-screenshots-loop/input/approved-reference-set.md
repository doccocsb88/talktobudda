## Production Goal

Do not re-invent the campaign.

The next passes should:
- keep the same 6-screen sequence
- keep the same headline/subtitle copy unless a run explicitly requests copy edits
- tighten crop and spacing so the 6 screens feel like one system
- make the mockup scale and placement read as intentionally matched from screen to screen

## Alignment Spec

All 6 screens should share the same vertical structure:

1. top badge / page number zone
   - same top offset on every screen
   - same circular badge size
2. headline block
   - same top anchor relative to the canvas
   - same max width
   - same intended block height, even when line count varies
3. subtitle block
   - same width as the headline system
   - same spacing below headline
   - same reserved height before the device starts
4. device / mockup block
   - same overall scale class across all 6 screens
   - same bottom anchoring logic
   - same safe left/right margin unless a deliberate off-center composition is part of the chosen layout

## Crop Rules

- crop the UI inside the phone so the key content sits in a comparable vertical band across all screens
- avoid one screen showing too much empty bezel area while another feels zoomed in
- prefer slightly tighter crops on denser screens rather than shrinking the whole device
- keep the visible app chrome believable; do not crop so aggressively that the UI feels fake or cut off

## Decision Rule

If a new output matches this reference set in copy and general composition, the next action is not concept regeneration.

The next action is:
- align headline block
- align subtitle block
- align device footprint
- export individual production assets
