# Brandkit Prompt Template For App Icon Exploration

Use this template with the `brandkit` skill, then adapt the specifics to the current brief.

```text
Use the brandkit skill to create a premium app-icon exploration board for TalkToBudda.

Brand strategy:
- category: spiritual guidance / Buddhist-inspired wellness companion
- audience: people seeking calm, reflection, emotional support, and gentle daily rituals
- emotional promise: clarity, compassion, wisdom, quiet strength
- cultural position: modern spiritual product, not old-fashioned religion, not generic meditation app
- avoid: cartoon Buddhism, ornate temple imagery, crowded mandalas, portrait illustration, soft cliché wellness gradients

Create a compact premium board that focuses on app icon concepting.

Requirements:
- show 3 distinct icon directions
- each direction must be symbolic, minimal, and scalable
- each direction must work without text
- use brand-led color logic based on deep forest green, warm near-black, and soft ivory
- include subtle construction or reduction logic where useful
- emphasize small-size legibility and App Store differentiation
- present the concepts like a premium brand review board, not a random moodboard

Direction targets:
1. safe premium calm: lotus + quiet light
2. differentiated modern guidance: speech path + halo or negative-space insight
3. bold shelf impact: abstract spiritual mark with strong silhouette and contrast

Composition:
- `2 x 2` or `2 x 3` layout
- one overview panel
- one close-up icon panel
- one construction/detail panel
- one usage panel on iPhone home screen if helpful

Output style:
- restrained
- cinematic
- expensive
- minimal typography
- coherent presentation grid
```

If the first pass is too illustrative, rerun with these corrections:
- simplify the symbol
- remove extra petals, rays, or decorative details
- increase silhouette clarity
- reduce gradients
- make it feel more ownable and less stock wellness
